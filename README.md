# PF-MARL

Privacy-Preserving Federated Multi-Agent Reinforcement Learning for Urban Epidemic Control.

## Overview
This repository contains the implementation of a Multi-Agent Reinforcement Learning (MARL) framework integrated with Federated Learning (FL) and Differential Privacy (DP) for managing urban epidemics.

## Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run centralized experiment:
   ```bash
   python experiments/run_experiment.py
   ```
